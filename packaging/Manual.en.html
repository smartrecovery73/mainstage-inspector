MainStage Inspector 1.0.0

User manual · macOS 15 or later · Apple Silicon (M1 or later).

The app interface is currently in Italian. This manual provides English explanations alongside the actual Italian control names. The installer includes the Italian manual; this English edition is supplied separately with the Release.

Installation

Open MainStage-Inspector-1.0.0-AppleSilicon.pkg and follow Installer. The app is installed in Applications → MainStage Inspector. Installation for all users may require an administrator password. Close any earlier version first.

Python and Zstandard, used to decode supported compressed plugin states, are already included. You do not need to install Python, Homebrew, Xcode or MainStage to read a concert.

This distribution has no Developer ID signature or Apple notarization. macOS may warn about or block it according to the Mac’s security settings and policies. The ad hoc signature checks integrity but does not certify the developer’s identity. Do not disable system security protections.

Opening a concert

Launch the app and choose Apri concerto (Open concert) in the toolbar to select a .concert package. Wait for analysis, then select a Set or Patch on the left. The app reads concert files without modifying them or running plugins.

Rianalizza (Reanalyze) reads the concert again. Save changes in MainStage first if you want to inspect an updated concert.

Channel strips

  • Ingresso MIDI (MIDI input): keyboard label in the layout, assigned device and port from the saved files.
  • Zona tastiera (Keyboard zone): local note range, velocity and transposition. The note naming convention is MIDI 60 = C4.
  • Plugin and presets: plugin name and internal preset name when the format is supported. The channel strip name and host AU setting are separate data.
  • Mute, Solo and Bypass: saved state indicators. MIDI layer bypass is separate from individual plugin bypass.
  • Alias: identifies the shared original strip. The displayed MIDI input remains the alias’s own assignment.

Mostra anche gli strip dei livelli superiori (Also show strips from higher levels) displays strips saved at Set or Concert level. It does not reconstruct the Patch’s effective overrides.

Search

Use the search field on the left and select Tutto (All), Hardware or Preset. Search for a keyboard, port, plugin or sound name. Matching is based on each node’s local strips. A matching Patch still displays all its strips.

Concert summary

Riepilogo (Summary) shows Set, Patch and strip counts, required plugins, assigned keyboards and shared aliases. Counts distinguish non-alias occurrences from references including aliases. They do not measure CPU or memory usage and do not guarantee that plugins are installed.

Export

In Esporta (Export), choose:

  • Report stampabile (.html) (Printable report): readable concert summary and details. Open it in a browser and print it or save it as PDF using the browser’s print dialog.
  • Dati completi (.json) (Complete data): structured analysis and diagnostic information.

Reports may contain concert names and paths. Review them before sharing.

Startup and preferences

The app starts with no previous concert, search or selection restored. It does not store the previous concert path, selected Patch or search. Version 1.0.0 removes legacy session keys and the app’s recent-document list without deleting concerts or reports. Only window position and size are remembered. Explicitly opening a .concert file still loads that file.

Limitations

MainStage packages have no complete public specification. Readers have been checked against test files; other formats or versions may need changes. Unreadable data is reported as unavailable and must not be interpreted as absent plugins or devices.

MIDI inputs describe saved assignments, not physical connections. Zones are local, and Concert/Set/Patch overrides are not resolved. Plugin bypass is read for recognized CST 6.14 headers. A saved preset name may remain unchanged after sound edits.

Official Audio Unit names come from component metadata installed on the destination Mac. Missing components may appear under abbreviated saved names. Open the concert in MainStage to check actual sound and audio operation.

Troubleshooting

ProblemCheck
Concert does not openSelect the complete .concert package, containing Concert.patch/data.plist.
Outdated dataSave in MainStage and choose Rianalizza in the Inspector.
Preset unavailableThe saved state format may be unsupported or may not contain the name in a recognized form.
Runtime not foundReinstall from the complete package. Do not extract or move files inside the app bundle.

Uninstalling

Quit MainStage Inspector and move the app from Applications to Trash. Concerts and exported reports remain where you saved them. Local preferences are not automatically removed.
